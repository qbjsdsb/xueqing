# 学情闭环

> 机构教学协作与学生成长管理平台

## 项目定位

“学情闭环”不是传统教务系统，也不是 Excel 的网页化版本。它面向教培机构内部多教师协作场景，围绕学生连续成长档案与学情问题闭环，帮助机构回答三个问题：

1. 这个学生现在最需要解决什么？
2. 老师下一步应该做什么？
3. 经过教学干预后，问题到底有没有稳定解决？

## 核心原则

- 一个学生在一个机构内只有一份主档案。
- 原始事实只记录一次，周报、阶段复盘等尽量自动生成。
- 学情结论尽量附带证据。
- 每个未解决问题都必须有下一步行动。
- 老师尽量少填，系统尽量多自动。
- AI 只做副驾驶，不静默修改正式学情。
- 数据属于机构，不属于单个教师账号。

## 第一阶段目标

V1 先解决机构内部真实使用：

- 多教师独立账号
- 机构 / 校区 / 角色权限
- 学生统一档案
- 教师—学生—学科关系
- 学情案例与证据
- 教学干预与检测
- 课堂快速记录
- 今日工作台
- 操作历史
- 云端统一数据

## 技术方向

客户端优先采用 Flutter，面向 Windows 与 Android；云端采用 Supabase（PostgreSQL + Auth + Storage + RLS），源码由 GitHub 管理。

> 当前仓库为项目初始化阶段。开发与测试阶段不得提交真实学生隐私数据、账号密码、密钥或家长信息。
